# Agentic NetOps

A small multi-agent application for monitoring and diagnosing network telemetry using Google ADK, MCP, and Gemini.

## Quick start

1. Create and activate a virtual environment.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the app:
   `uvicorn app.main:app --reload`

## Project structure

- `app/` contains the FastAPI application and agent modules
- `tests/` contains automated tests
- `docs/` will hold implementation notes and architecture diagrams
